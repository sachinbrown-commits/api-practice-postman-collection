# Postman API Practice

This repository contains API requests created using Postman for learning and practicing API testing.

## Tools Used
- Postman
- GitHub

## APIs Tested
The following public APIs were used for testing:

1. JSONPlaceholder API
2. Dog API
3. Rest Countries API

## Request Methods Used
The collection includes examples of common HTTP request methods:

- GET – Retrieve data from an API
- POST – Send data to an API
- PUT – Update existing data
- DELETE – Remove data

## Collection Contents

The Postman collection includes requests such as:

- GET All Posts
- GET Post by ID
- POST Create Post
- GET Random Dog Image
- GET Country Information

## How to Use This Collection

1. Download the file `api-practice-postman-collection.json`
2. Open Postman
3. Click **Import**
4. Upload the JSON file

The requests will automatically appear in your Postman workspace.
